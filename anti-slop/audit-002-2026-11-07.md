# Anti-Slop UI & Accessibility Audit 002 — Report & Remediation

- **Project:** ServerWatch Desktop (Go + Wails + Svelte)
- **Date:** 2026-11-07
- **Mode:** Mode 2 (After / Post-Implementation Audit)
- **Target Components:** `SettingsView.svelte`, `UptimeView.svelte`, `App.svelte` (Modal Restore & Active Backups), `style.css`
- **Standard:** Anti-Slop Rules for AI Coding Agents (R-01 to R-38)
- **Status:** **ALL 9 APPROVED FINDINGS RESOLVED (100% FIXED)**

---

## Remediation Log

| No | Temuan Masalah | Aturan | Status | Detail Perbaikan |
|---|---|---|---|---|
| **[1]** | Token CSS `--card` tidak terdefinisi di `:root` | **R-34**, **R-01** | **FIXED** | Seluruh penggunaan `var(--card)` pada stepper status dan kontainer rincian modal backup aktif di `App.svelte` diganti dengan token baku `var(--panel-2)`. |
| **[2]** | Kontras warna teks status `--crit` di bawah standar WCAG AA (4.08:1) | **R-25** | **FIXED** | Variabel `--crit` di `style.css` dinaikkan kecerahannya dari `#e5534b` ke `#ea655e`, meningkatkan rasio kontras dari 4.08:1 ke 4.68:1 (lulus standar WCAG AA 4.5:1 untuk teks normal). |
| **[3]** | Seluruh toggle switch pengaturan tidak memiliki accessible name/label | **R-32** | **FIXED** | Ditambahkan atribut `aria-label` yang deskriptif pada 9 elemen checkbox switch di `SettingsView.svelte` (misal `aria-label="Aktifkan Telegram Bot Alerting"`). |
| **[4]** | Tombol aksi simbol `✕` (hapus & close modal) tanpa `aria-label` | **R-32**, **R-15** | **FIXED** | Ditambahkan `aria-label="Tutup modal"`, `aria-label="Tutup wizard restore"`, `aria-label="Tutup modal proses backup"`, serta `aria-label="Hapus monitor {mon.name}"` dan `title="Hapus monitor {mon.name}"`. |
| **[5]** | Ukuran tap target tombol aksi di bawah batas minimum (< 28px) | **R-03** | **FIXED** | Tombol "Buka Browser" di `UptimeView.svelte` dinaikkan dari 18px ke 28px (`height: 28px; padding: 0 8px`). Tombol "Tutup" banner dan "Cek Ulang" distandarisasi ke tinggi minimum 28px. |
| **[6]** | Semantik navigasi tab ARIA (`role="tablist"` & `role="tab"`) hilang pada subnav Settings | **R-24**, **R-32** | **FIXED** | Diterapkan atribut ARIA lengkap: `role="tablist"` pada kontainer, serta `role="tab"`, `id="tab-..."`, `aria-controls="panel-..."`, dan `aria-selected` pada setiap tab navigasi dan kontainer panelnya. |
| **[7]** | Global listener tombol `Escape` untuk menutup banner konfirmasi di Settings | **R-32** | **FIXED** | Ditambahkan listener `<svelte:window on:keydown={handleKeydown} />` di `SettingsView.svelte` untuk mendeteksi `Escape` dan menutup banner feedback secara otomatis. |
| **[8]** | Inkonsistensi token border-radius (*magic numbers* 5px dan 3px) | **R-11** | **FIXED** | Seluruh nilai radius acak `5px` dan `3px` diganti secara seragam menggunakan token desain resmi `var(--radius-sm)` (4px) dan `var(--radius-md)` (6px). |
| **[9]** | Tombol aksi tabel monitor Uptime kurang kontekstual ("Cek", "Edit") | **R-15** | **FIXED** | Ditambahkan atribut `title` dan `aria-label` deskriptif pada tombol tabel Uptime (misal `title="Periksa respons {mon.name} ({mon.target}) sekarang"`). |
