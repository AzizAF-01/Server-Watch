## Remediation Log

| No | Temuan | Aturan | Status | Detail Perbaikan |
|---|---|---|---|---|
| **[1]** | Em Dash (`—`) di modal scan DB | **R-02** | **FIXED** | Karakter `—` diganti dengan `:` yang natural dan bersih di `App.svelte:3025`. |
| **[2]** | Navigasi sidebar tanpa keyboard | **R-32** | **FIXED** | Seluruh elemen navigasi samping diubah menjadi `<button type="button" class="nav-item">` lengkap dengan state keyboard focusable dan styling di `style.css`. |
| **[3]** | Modal tidak bisa ditutup tombol `Escape` | **R-32** | **FIXED** | Ditambahkan listener global `<svelte:window on:keydown={handleGlobalKeydown} />` untuk mendeteksi `Escape` dan menutup modal aktif secara otomatis. |
| **[4]** | Indikator fokus hilang (`outline: none`) | **R-32** | **FIXED** | Diberikan efek fokus visual pada `.search:focus-within`, `.terminal-header select:focus`, `.terminal-input-wrap:focus-within`, dan `.btn:focus-visible`. |
| **[5]** | Kontras warna teks `--dim` rendah | **R-25** | **FIXED** | Variabel `--dim` dinaikkan kecerahannya dari `#6b727c` menjadi `#8e95a0`, meningkatkan rasio kontras dari 3.67:1 ke 5.6:1 (memenuhi standar WCAG AA 4.5:1). |
| **[6]** | Label form tidak terhubung ke input ID | **R-32** | **FIXED** | Mengganti label non-kontrol menjadi `div.label`, dan menambahkan atribut `id="restore-custom-db"` yang tertaut ke `for="restore-custom-db"`. |
| **[7]** | Ukuran tap target tombol aksi sempit | **R-03** | **FIXED** | Tombol aksi kompak distandarisasi ke tinggi minimum 28px dengan padding nyaman `4px 10px` untuk layar sentuh / high-DPI. |
| **[8]** | Inkonsistensi token border-radius | **R-11** | **FIXED** | Didefinisikan token desain `--radius-sm: 4px`, `--radius-md: 6px`, `--radius-lg: 8px` di `:root` dan diterapkan secara seragam pada panel, tombol, chip, dan modal. |
| **[9]** | Label tombol kurang kontekstual ("Detail") | **R-15** | **FIXED** | Ditambahkan tooltip atribut `title="Lihat Telemetri & Dasbor Detail Server {srv.name}"` pada tombol aksi daftar server. |
